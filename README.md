# Investigación Operativa - Verificador Simplex / Primal-Dual 📊

Herramienta interactiva para la formulación, resolución y pasaje de tablas Primal ⇄ Dual en problemas de Programación Lineal (Método Simplex).

---

## 🚀 Uso Online

Podés usar la herramienta directamente desde el navegador (sin necesidad de instalar ni descargar nada):

👉 **[Abrir Verificador Primal-Dual](https://Tomibernardez04.github.io/investigacion-operativa/)**

---

## 💻 Uso Local (Descarga)

Si preferís tenerlo en tu computadora:

1. Cloná o descargá este repositorio en formato `.zip` (`Code` -> `Download ZIP`).
2. Abrí el archivo `Verificador_Pasaje_Primal_Dual.html` con cualquier navegador web (Chrome, Edge, Firefox, Brave, Safari).
3. ¡Listo! Funciona de manera 100% interactiva y local.

---

## 🛠️ Características

- Entrada dinámica de funciones objetivo y restricciones.
- Conversión y reglas canónicas entre Primal y Dual.
- Visualización de tablas Simplex paso a paso con variables básicas, costos reducidos y coeficientes técnicos.
- Renderizado matemático de alta calidad con KaTeX.
